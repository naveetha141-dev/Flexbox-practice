This is a simple practise project created to learn and understand css flexbox cocepts.

## What I build
    A purple background container with four small boxes inside it,aligned using flexbox.
##Concepts used

    -align-items
    -gap
    -flex-wrap
##Purpose
 This project is made for practise only to improve my frontend development skills using CSS flexbox.
